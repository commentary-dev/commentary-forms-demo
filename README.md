# Commentary Forms Demo

This public repository hosts the polished Commentary Forms demo. The `main`
branch stays intentionally small; the demo content lives on the stable
`demo/full-power` branch so Commentary can open it as a Git-backed review.

Open the demo branch in Commentary:

```text
/review/github/commentary-dev/commentary-forms-demo/document?branch=demo%2Ffull-power&file=docs%2Flaunch-readiness.md&demo=1
```
