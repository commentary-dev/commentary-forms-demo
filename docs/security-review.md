# Security Review Intake

This document shows a narrower security form that teams can keep in the same
repository as the release documents it protects.

## Security Summary

The reviewer should confirm data classification, ownership, PII handling, and
mitigation plans before the release is approved.

## Notes For Reviewers

- Keep discussion in document comments when the answer needs context.
- Keep final approval fields in the form so agents can read consistent values.
- Use the mitigation plan field when risk score is high.
