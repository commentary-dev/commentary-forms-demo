# Launch Readiness Review

This release review demonstrates the full current power of Commentary Forms in
a GitHub repository. The document remains normal Markdown that can be reviewed
with comments, anchors, file navigation, and diff tools. The embedded form below
collects structured answers that Commentary can validate and expose to agents.

## Release Context

| Area | Owner | Review focus |
| --- | --- | --- |
| Product | Launch team | Customer-facing scope and release date |
| Security | Security engineering | PII, risk, and required mitigations |
| Support | Customer experience | Runbook readiness and escalation paths |
| Operations | Platform | Rollout confidence and monitoring |

## Review Guidance

Use document comments for discussion about wording, launch risks, and follow-up
work. Use the form for final structured answers, because those values can be
validated, exported, and summarized for agents without scraping the Markdown.

## Completion Criteria

- Required release, owner, and signoff fields have valid values.
- Conditional PII details are completed when customer data is involved.
- The final review page has been checked before submission.
- Any Markdown comments have been resolved or moved into the release checklist.
